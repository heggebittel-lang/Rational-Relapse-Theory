The English manuscript and the Chinese translation are two language representations of the same v9.0 scholarly object. The translation does not create a separate theoretical version.

The repository records the translation source and exact SHA-256 hashes of the prepared English/Chinese release files before the unified GitHub Release is created. The intended archival chain is:

1. dated source/manuscript files;
2. public Git commit history;
3. one bilingual GitHub Release tagged `v9.0`;
4. Zenodo archival deposit and DOI;
5. DOI added back to the repository metadata.

This chain provides a public, timestamped provenance record for the manuscript and its translation. A DOI is a persistent identifier and citation anchor; it is not by itself a legal adjudication of authorship or priority.
