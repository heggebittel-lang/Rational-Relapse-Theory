## Manuscript identity

This is the current endpoint of the research program. It begins from exact compensated current comparisons and asks what can be identified about a target environment when its baseline choice is observed but the neighboring compensated comparisons required for the direct comparative static are missing.

The paper deliberately treats compensated measurement, additive representation, cancellation, graph cycle spaces, rank/kernel arguments, finite differences, implicit-function comparative statics, graph potentials, and standard dynamic consequences as established machinery. The substantive issue is the information supplied by comparison support: current-side balanced comparisons can eliminate unrestricted current-node values while leaving continuation contrasts that identify local functionals needed for the target response.
