# v9.0 Release Notes

## Compensated Current Choice and Counterfactual Identification

**Chinese title:** 《补偿性当前选择与反事实识别》  
**Original internal label:** `Compensated_Current_Choice_v38_Economic_Grounding`

This release is the bilingual archival endpoint of the Rational Relapse Theory research program. It contains the English manuscript and a Chinese translation of the same scholarly object.

The paper studies a counterfactual identification problem: the target environment's baseline current choice is observed, but the neighboring compensated comparisons needed for the direct comparative static are missing. The analysis uses compensated binary comparisons, cancellation, cycle-space contrasts, finite differences, and standard comparative-static/dynamic tools. These mathematical tools are treated as established machinery; the substantive focus is the information supplied by comparison support.
