# v9.0 中文版源码

本目录包含 **v9.0 — _Compensated Current Choice and Counterfactual Identification_** 的完整中文翻译分段源码。中文标题为 **《补偿性当前选择与反事实识别》**。

这是一份与 v9.0 英文原稿对应的语言版本，不构成新的理论版本。数学公式、定理结构、编号体系、证明顺序与参考文献尽量保持与英文稿一致；中文稿的目的，是便于中文读者阅读、分享与讨论。

## 编译

主文件位于上一级目录：`../v9.0_zh.tex`。编译时还需要上一级目录中的四个共享图文件：

- `fig1_colored.jpg`
- `fig2_locus.jpg`
- `fig3_cancellation.jpg`
- `fig4_critical.jpg`

建议使用 XeLaTeX 编译。正式 GitHub Release / Zenodo 归档时，将同时放入英文 PDF、英文 TeX、中文 PDF、中文 TeX 与共享图文件。

## 图的语言

为避免在数学图示的二次编辑中引入符号或几何错误，中文稿保留英文原图，并在正文中加入中文图示说明。图 4 的识别阶梯另在 LaTeX 中加入中文标签。以后如制作完全中文化的图，只应作为同一 v9.0 中文呈现的排版改进，不改变理论内容。
