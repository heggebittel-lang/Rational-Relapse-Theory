## Manuscript identity

This version translates the project back into standard revealed-preference and compensated-choice language. It uses compensated switching thresholds and money-metric comparisons to study state-dependent valuation, reinforcement, recovery values, cross-experiment compatibility, and the common state-dependent value geometry revealed by two compensated-choice experiments.

The Chinese manuscript is an archival translation of the same historical v7.0 object. It does not constitute a new theoretical version.
