## Manuscript identity

This version shifts the primitive object from a recovery utility function to target-relative continuous paths and path-generated ledgers. It studies additive measurement on a domain that is not closed under arbitrary addition and develops a finite-cancellation / Stieltjes-representation route. Rational addiction is presented as a leading economic application rather than as the source of the representation theorem.

The central boundary result is that location-free common-increment cancellation (LC-A), even in its formal-increment form, does not imply finite cancellation on the path-generated domain. The positive representation result instead treats finite cancellation as a separate condition and derives a four-module Stieltjes representation under additional sufficient regularity assumptions.

## Translation note

The Chinese file is an archival translation of the same historical manuscript, not a new theoretical version. The main text preserves the definitions, assumptions, propositions, equations, and economic interpretation. For readability, some repetitive prose in the proof appendices is compressed while the core constructions and derivation chains are retained. When citing the work, cite the `v5.0` release / Zenodo DOI rather than treating the Chinese translation as a separate paper.

The original JME submission number is retained only for provenance and correspondence matching.
