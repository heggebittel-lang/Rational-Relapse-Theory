**Original submission label:** JME-S-26-00480  
**Language:** English  
**Planned release tag:** `v5.0`  
**Zenodo DOI:** pending release

## Manuscript identity

This version shifts the primitive object from a recovery utility function to target-relative continuous paths and path-generated ledgers. It studies additive measurement on a domain that is not closed under arbitrary addition and develops a finite-cancellation / Stieltjes-representation route. Rational addiction is presented as an economic application rather than as the source of the representation theorem.
