# Priority and provenance — v5.0

This directory preserves one historical stage of the Rational Relapse Theory research archive.

- Archive label: **v5.0**
- Original manuscript title: **Additive Measurement on Path-Generated Domains: Directed Recovery in Rational Addiction**
- Original submission label: **JME-S-26-00480**
- Author: **Yushang Cheng**
- ORCID: **0009-0001-3218-6423**
- Archive year: **2026**
- License: **CC BY 4.0**, unless a file states otherwise

The v5.0 archive label is chronological and is not the original manuscript version number. It was assigned when the research program was reorganized into a continuous v1.0–v9.0 public archive.

The English manuscript is the historical source object. `v5.0_zh.pdf` and `v5.0_zh.tex` are an archival Chinese translation of the same manuscript and should not be treated as a separate theoretical contribution.

The intended preservation chain is:

1. Git commit containing the version metadata and checksums.
2. GitHub Release tagged `v5.0` containing the English and Chinese archival files.
3. Zenodo archival synchronization of that release.
4. A version-specific Zenodo DOI recorded back into the repository README.

`SHA256SUMS.txt` fixes the exact byte-level identity of the prepared release files before the DOI is minted. The Git history, release tag, Zenodo timestamp, DOI, and hashes together provide a public provenance trail. They establish a citable record of authorship and priority; they are not a substitute for the underlying legal rules of copyright.
