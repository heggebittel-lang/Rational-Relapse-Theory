## Manuscript identity

This version generalizes the path approach by studying which features of a one-dimensional target-relative adjustment history survive chronology-coarse additive evaluation. It develops an exact passage-compression perspective, a universal passage carrier, and additive-choice consistency conditions on a non-additively-closed history domain.
