## Manuscript identity

This version reduces the preceding two-experiment structure toward a single monetary-comparison protocol in a recursive environment. The paper asks what compensated current choice can identify about continuation responses and counterfactual comparative statics. Its main results are a sharp transition-matching criterion, same-index propagation under a recursive marginal restriction, and a sharp characterization of the response directions identified after propagation.

## Source-reconstruction note

The original LaTeX source for this historical version was lost. The surviving PDF is therefore the authoritative English artifact. In August 2026, a new archival source file was reconstructed from that PDF for preservation and reproducibility. The reconstructed source is not asserted to be byte-for-byte or typographically identical to the lost original source; it preserves the paper's text, mathematical statements, equation structure, and references in a clean compilable form.
