# v8.0 — Priority and provenance

This folder preserves the historical manuscript **Compensated Choice and Recursive Counterfactual Identification**, originally stored under the internal label `recursive_monetary_comparison_core_theory_v9_1`.

## Author

Yushang Cheng

## Provenance chain

1. The surviving English PDF was compiled on 21 August 2026 and is preserved as `v8.0.pdf`.
2. The original `.tex` source was subsequently lost.
3. On 23 August 2026, an archival English source (`v8.0_reconstructed.tex`) was reconstructed directly from the surviving PDF.
4. A Chinese archival translation (`v8.0_zh.tex` / `v8.0_zh.pdf`) was produced from the same reconstructed structure.
5. Exact SHA-256 hashes are recorded in `SHA256SUMS.txt` before the GitHub Release / Zenodo deposit.

The surviving original PDF is the authoritative historical artifact. The reconstructed English source is a preservation aid, not evidence that it is the original source file. The Chinese document is a translation of the same version, not a separate theoretical paper.
