> **Important:** This repository preserves the development of a research program that began as an addiction-specific model of endogenous exit and rational relapse and later evolved into a broader compensated-choice and counterfactual-identification project. Early versions are retained for provenance. Their terminology, assumptions, and novelty claims do **not** necessarily represent the author's current position.

## Current endpoint

The current endpoint of the project is **v9.0 — _Compensated Current Choice and Counterfactual Identification_**. It treats compensated comparison, cancellation, graph/cycle-space arguments, finite differences, and standard dynamic consequences as established tools; the substantive question is the information structure needed to identify a counterfactual local choice response when nearby compensated comparisons are missing in the target environment.

This archive is intentionally versioned rather than rewritten retroactively. A reader can therefore follow how the project moved from an addiction-specific conjecture to a general identification problem.

For a compact bilingual navigation table, see **[ARCHIVE_INDEX.md](./ARCHIVE_INDEX.md)**. For the full version-by-version diagnosis — what each version added, how it was later criticized, and what the next version repaired — see **[WHY_THE_PROJECT_CHANGED.md](./WHY_THE_PROJECT_CHANGED.md)**.

## What each version added — and why it changed

The nine archived versions should not be read as nine repetitions of the same claim. Each version added a specific piece of structure, then exposed a new weakness that motivated the next one. Only v5.0 and v7.0 received explicit JME editorial / Associate Editor criticism; the other transitions reflect internal structural criticism, identification analysis, implementation concerns, or later literature audit.

| Version | What it added | What later came under attack | What the next version changed |
|---|---|---|---|
| **v1.0** | Endogenous exit/recovery value and adjustment friction, with oscillatory paths interpreted as rational relapse. | The mechanism was too thin and potentially driven by a particular functional form and complex-root construction. | **v2.0** built a complete dynamic model with steady states, comparative statics, and regime analysis. |
| **v2.0** | A full structural rational-addiction model with Bellman/Euler logic and long-run dynamics. | The model was more complete, but still rested on a highly specific recovery/exit primitive. | **v3.0** replaced the single recovery function with a broader function-family formulation. |
| **v3.0** | Function-family generalization and a more systematic treatment of adjustment friction. | Generalizing the function did not justify the deeper additive decomposition; recovery value could still be imposed rather than derived, with possible double counting. | **v4.0** moved to an axiomatic/representation perspective and target-relative recovery value. |
| **v4.0** | Target-relative recovery representation, reinforcement–substitution reversal, endogenous target formation, multiple steady-state boundaries, and recurrent dynamics. | The representation still began from strong structure, and the gap between theoretical objects and observable choice remained large. | **v5.0** moved the primitive to target-relative paths and path-generated ledgers, asking when additive measurement can be behaviorally supported. |
| **v5.0** | Additive measurement on a non-additively-closed path-generated domain, a counterexample separating common-increment cancellation from finite cancellation, and a Stieltjes-representation route. | **JME-S-26-00480:** the technical construction and counterexample were viewed as interesting, but the main representation theorem relied on strong global extension and Archimedean assumptions that already supplied much of the ordered-group structure needed for the conclusion. | **v6.0** separated exact passage compression from additive representation instead of treating one large representation theorem as the sole endpoint. |
| **v6.0** | Exact passage compression, universal passage carrier, path fibers, and a cleaner separation between historical compression and additive choice. | The mathematics was cleaner, but the economic observables were still too abstract: what would an economist actually observe? | **v7.0** returned to revealed preference and exact monetary switching thresholds as observable compensated-choice data. |
| **v7.0** | A compensated-choice formulation using two experiments to study state-dependent valuation, reinforcement, recovery value, and common value geometry. | **JME-D-26-00519:** the paper renamed familiar structures with extensive new terminology; once translated back, some results looked close to increasing differences, integrability, path independence, and other standard tools. The second experiment also lacked a convincing economic implementation. | **v8.0** abandoned the private terminology, treated the standard tools as standard, and compressed the design toward one monetary protocol in a recursive identification problem. |
| **v8.0** | Recursive counterfactual identification, transition matching, and same-index propagation under a recursive marginal restriction. | Further audit showed that tangent-space, rank/kernel, graph, and propagation machinery were not themselves credible novelty claims, and the fiber-level information set was stronger than the question the project ultimately wanted to answer. | **v9.0** reduced the problem to current-only observational equivalence and asked when enriched comparison support strictly adds identification power. |
| **v9.0** | A current-only structural identification condition, explicit nuisance-value elimination, continuation-information requirements, and a strict comparison between current-only and enriched support. | Final audit showed that compensated measurement, cancellation, cycle space, rank/kernel, finite differences, and the implicit-function theorem are all standard machinery. The remaining uncertainty is external: prior art for the structural information comparison, and credible institutions that provide recombinable continuation support. | **No v10.** The project stops expanding and is archived pending those external questions. |

The detailed retrospective is in **[WHY_THE_PROJECT_CHANGED.md](./WHY_THE_PROJECT_CHANGED.md)**. It explains each stage in four parts: what the version added, how it was attacked, what the next version repaired, and what still remained unresolved.

## What changed intellectually?

The project began from a simple question: can a rational-addiction model contain an endogenous force associated with doing less or exiting, rather than treating cessation only as an externally imposed commitment device? Early versions modeled such an exit term directly and used adjustment friction to generate oscillatory paths.

Successive versions then asked increasingly demanding questions about functional form, additive representation, double counting, path/history compression, compensated measurement, and identification. Literature auditing eventually showed that much of the mathematical machinery belongs to established revealed-preference, additive-measurement, graph, finite-difference, and dynamic-systems theory. The final stage therefore narrows the claim: the potentially substantive object is the **information structure and comparison support** required for counterfactual identification, not the standard tools used to analyze it.

## Preservation policy

- Earlier manuscripts are **not deleted or silently rewritten**.
- Each archive version receives its own folder and its own GitHub Release / Zenodo citation record.
- Each historical stage has a **version-specific Zenodo record** rather than relying on a whole-repository archive as the primary citation object.
- A translation or correction that materially changes a released manuscript should normally be issued as a new release/version rather than silently replacing the archived object.
- The repository's historical versions document provenance; they should not be read as simultaneous current claims.
